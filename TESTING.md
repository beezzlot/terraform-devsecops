|---|---|---|---|

| `CKV_YC_11` — security group назначена | `web` VM | FAIL | В блоке `network_interface` отсутствует `security_group_ids`. Проблему желательно исправить, чтобы явно ограничить сетевой доступ |

Обнаруженные проблемы связаны с отсутствием security group у виртуальных машин `web` и `api`. В текущей учебной конфигурации VM не имеют публичных IP, поэтому риск прямого доступа из интернета снижен. Однако отсутствие security group не позволяет явно описать разрешённые входящие и исходящие соединения.

Для production-окружения проблему необходимо исправить: создать security group с минимально необходимыми правилами и передать её идентификатор в `security_group_ids`. Для текущей учебной работы проблема зафиксирована в отчёте как результат статического анализа и не исправлялась, чтобы показать работу Checkov.
